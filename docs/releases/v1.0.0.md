## Image verification

After the publish workflow produces an image digest, set:

```sh
IMAGE="ghcr.io/crimson9066/fortress@sha256:<published-digest>"
```

Verify the keyless Cosign signature:

```sh
cosign verify \
  --certificate-identity-regexp '^https://github.com/crimson9066/Fortress/.github/workflows/publish.yml@refs/heads/main$' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  "$IMAGE"
```

Verify the CycloneDX SBOM and SLSA provenance attestations:

```sh
cosign verify-attestation --type cyclonedx \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  "$IMAGE"
cosign verify-attestation --type slsaprovenance \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  "$IMAGE"
```

The publish workflow attaches the SBOM and provenance to the image digest;
there is no checked-in SBOM for an unpublished digest.

## Create and verify the signed tag

Configure a local GPG or SSH signing key, then run these commands manually:

```sh
git tag -s v1.0.0 -m "Release v1.0.0"
git tag -v v1.0.0
```

Publishing the tag or creating a GitHub release is intentionally out of scope
for this session.
