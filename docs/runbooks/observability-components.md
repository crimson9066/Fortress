# Observability components

Prometheus, Alertmanager, Grafana, and Falcosidekick run with non-root
security contexts, resource limits, and namespace NetworkPolicies. Grafana's
admin credentials are generated by External Secrets and are never committed.

Falco is the documented exception: syscall capture requires host access and
the Falco namespace uses Pod Security `privileged`. Falco uses the modern eBPF
driver where the kind host kernel supports it. If modern eBPF cannot attach,
the deployment must be treated as unhealthy and investigated; automatic
fallback to a less-auditable driver is not enabled.
